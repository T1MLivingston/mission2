    A · File types — JPEG, PNG, PDF

    .jpg / .jpeg

    Joint Photographic Experts Group

    The photo format.

    • Use for: photos
    • Not for: screenshots or text
    • Lossy — throws away detail to get small. It never comes back.

    .png

    Portable Network Graphics

    The screenshot format.

    • Use for: screenshots, text, logos
    • Not for: huge photos
    • Lossless, and see-through. Drag the bot — the checkers keep showing.

    .pdf

    Portable Document Format

    The turn-it-in format.

    • Use for: anything graded
    • Not for: work someone must edit
    • Locks the page. Same on every device.

    B · Python indexing

    01 Counting starts at zero

    Python counts how far from the start. The first bot is zero steps in.

    crew = ["Alpha", "Beta", "Charlie", "Delta", "Echo"] crew[0] # "Alpha" crew[1] # "Beta" crew[2] # "Charlie"
    02 Negative numbers count backward

    -1 is the last one.

    crew[-1] # "Echo" ← last crew[-2] # "Delta"
    03 len() and the last legal spot

    5 bots: len is 5, highest index is 4.

    len(crew) # 5 crew[4] # "Echo" ← last legal spot crew[5] # IndexError

    Last index = len − 1.

    05 You can do math in the brackets

    Python works out the math first, then goes to that address.

    i = 1 crew[i] # "Beta" ← i is 1 crew[i + 1] # "Charlie" ← 1 + 1 = 2 crew[i - 1] # "Alpha" ← 1 - 1 = 0 crew[len(crew) - 1] # "Echo" ← 5 - 1 = 4, the last one

    Add too much and you fall off the end: crew[3 + 3] is crew[6] — IndexError.

    04 Slices stop early

    crew[start:stop] stops just before stop.

    crew[1:3] # ["Beta", "Charlie"] ← 3 left out crew[:2] # ["Alpha", "Beta"] crew[3:] # ["Delta", "Echo"]

    Words work the same way: "PYTHON"[0] is "P".

      Python

      Data Types

      Every value has a type. The type decides what you can do with it.

      int — whole numbers

      Counting things. No decimal point.

      points = 20 ports = 4

      float — decimal numbers

      Measuring things. The dot makes it a float, even 2.0.

      speed = 2.5 volts = 3.3

      str — text (a "string")

      Letters, in quotes. Each letter has an index, exactly like a list.

      name = "Alpha" name[0] # "A"

      bool — True or False

      Answers a yes-or-no question. Capital T, capital F.

      charged = True online = False

      list — many values in order

      Square brackets, commas between. Indexed from 0. A list can hold any of the types above.

      crew = ["Alpha", "Beta"] specs = [16, 512, 2.5]
      Quotes change everything. 7 does math. "7" is text. Check with type(7).
