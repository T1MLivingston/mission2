File types + Google Drive

JPEG, PNG, PDF — and where your file goes

The letters after the dot tell every device what kind of file it is. Pick the wrong one and your work shows up blurry.

.jpg / .jpeg

Joint Photographic Experts Group

The photo format.

  • Use for: photographs
  • Not for: screenshots or text
  • Lossy — throws away detail to get small, and never gets it back.

.png

Portable Network Graphics

The screenshot format.

  • Use for: screenshots, text, logos
  • Not for: huge photos
  • Lossless, and it can be see-through. The checkerboard means no background.

.pdf

Portable Document Format

The turn-it-in format.

  • Use for: reports, anything graded
  • Not for: work someone else must edit
  • Locks the page. Your Chromebook, my laptop, a phone — same page.

Python

Indexing: finding one bot in a list

A list holds many bots. An index is the address of one of them. Read the cards, play in the lab, then take the check.

01 Counting starts at zero

Python counts how far from the start something is. The first bot is zero steps in.

crew = ["Alpha", "Beta", "Charlie", "Delta", "Echo"] crew[0] # "Alpha" crew[1] # "Beta" crew[2] # "Charlie"
02 Negative numbers count backward

-1 is the last one. No counting the whole list.

crew[-1] # "Echo" ← last crew[-2] # "Delta"
03 len() and the last legal spot

5 bots means len is 5 — but the highest index is 4.

len(crew) # 5 crew[4] # "Echo" ← last legal spot crew[5] # IndexError

Last index = len − 1.

04 Slices stop early

crew[start:stop] stops just before stop. The stop number never comes along.

crew[1:3] # ["Beta", "Charlie"] ← 3 left out crew[:2] # ["Alpha", "Beta"] crew[3:] # ["Delta", "Echo"]

Words work the same way: "PYTHON"[0] is "P".

Python

Data Types

Every value in Python is some type. The type decides what you are allowed to do with it. You will use all five of these when you start programming your bot.

int — whole numbers

Counting things. No decimal point.

points = 20 ports = 4

float — decimal numbers

Measuring things. The dot makes it a float, even 2.0.

speed = 2.5 volts = 3.3

str — text (a "string")

Letters, in quotes. Each letter has an index, exactly like a list.

name = "Alpha" name[0] # "A"

bool — True or False

Answers a yes-or-no question. Capital T, capital F.

charged = True online = False

list — many values in order

Square brackets, commas between. Indexed from 0. A list can hold any of the types above.

crew = ["Alpha", "Beta"] specs = [16, 512, 2.5]
Quotes change everything. 7 is an int you can do math with. "7" is a string — text that happens to look like a number. Ask Python which one you have with type(7).
