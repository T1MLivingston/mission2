Stage 03 · Training · Python

Indexing: how Python finds one item in a list

A list holds many values. An index is the address of one of them. Read the four cards, play with the index lab until the pattern clicks, then pass the check to earn build credits.

01 Counting starts at zero

Python does not count 1, 2, 3. It counts how far from the start an item is. The first item is zero steps from the start, so its index is 0.

# a list of five crew robots crew = ["Nova", "Byte", "Piston", "Quark", "Echo"] crew[0] # "Nova" ← first item, zero steps in crew[1] # "Byte" crew[2] # "Piston"

Square brackets after the list name mean “go get the item at this address.”

02 Negative indexes count back from the end

You often want the last item without counting the whole list. Negative indexes start at the end: -1 is the last item, -2 is the one before it.

crew[-1] # "Echo" ← last crew[-2] # "Quark"

There is no -0, because 0 already means the first item.

03 len() and the last legal address

len(crew) counts the items — it counts like a human, starting at 1. So a 5-item list has len of 5, but its highest index is 4.

len(crew) # 5 ← how many items crew[4] # "Echo" ← last legal index crew[5] # IndexError: list index out of range

Last index = len(list) − 1. Asking for an index that does not exist crashes the program with an IndexError. That error is not a bug in Python — it is Python telling you that you asked for an address that was never built.

04 Slicing takes a range — and stops early

Two numbers with a colon takes a slice: crew[start:stop]. It begins at start and stops just before stop. The stop index is never included.

crew[1:3] # ["Byte", "Piston"] ← 3 is NOT included crew[:2] # ["Nova", "Byte"] ← empty start = from 0 crew[3:] # ["Quark", "Echo"] ← empty stop = to the end

Strings work the same way — a string is a list of characters: "PYTHON"[0] is "P" and "PYTHON"[-1] is "N".

Stage 04 · Training · File Types + Google Drive

JPEG, PNG, PDF — and where your file goes

The three letters after the dot in a filename are the extension, and they tell every device what kind of file it is opening. Pick the wrong one and your work opens blurry, or does not open at all. Then: what Google Drive actually is, and how to get a file into it.

.jpg / .jpeg

Joint Photographic Experts Group

The photo format. Built to make pictures of the real world small enough to send.

  • Best for: photographs, camera shots, big colorful images
  • Avoid for: screenshots, text, sharp lines, logos
  • Lossy — it permanently throws away detail to shrink the file. Save it over and over and it slowly turns to mush.
  • No transparency. Every JPEG is a solid rectangle.

.png

Portable Network Graphics

The screenshot format. Keeps every pixel exactly as it was.

  • Best for: screenshots, code, diagrams, logos, anything with text in it
  • Avoid for: huge photos when file size matters
  • Lossless — nothing is thrown away, so small text stays sharp. Files are bigger.
  • Supports transparency — that checkerboard means “no background here.”

.pdf

Portable Document Format

The turn-it-in format. A frozen page that looks identical everywhere.

  • Best for: reports, multi-page documents, anything being printed or graded
  • Avoid for: work someone else needs to edit
  • Locks in layout, fonts, and page breaks. Your Chromebook, my laptop, a phone — same page.
  • Can hold many pages; a JPEG or PNG is always exactly one image.

Google Drive: what it actually is

Desktop vs. online versions

Google Drive is storage that lives on Google's computers instead of yours. When you upload a file, a copy travels over the internet to a data center and sits there. Sign in on any device with your school account and that same file is waiting — the Chromebook in this room, a laptop at home, a phone.

That is the difference between local storage (the Downloads folder on this specific machine — lose the machine, lose the file) and cloud storage. It is also why Drive has an online version in the browser and a desktop version that syncs a folder on your computer. Same files, two front doors.

States of data. Your report is at rest when it is sitting saved in Downloads or in Drive. It is in transit while it is uploading across the network. It is in use while it is open on your screen. Closing the tab mid-upload interrupts data in transit — which is exactly why a half-uploaded file never shows up.

How to get there

  • Type drive.google.com in the address bar — or click the 9-dot grid (⋮⋮⋮) at the top right of any Google page and choose Drive.
  • Check the account circle in the top right. It must be your school account. Personal Gmail cannot see the class folder.
  • In the left sidebar open Shared with me (or Shared drives), find the class folder, then open Mission 2.

Name it exactly like this

Naming convention

Rename the file before you upload it. Last name first, then first name, then the mission — no spaces, underscores between the parts, and keep the extension the computer gave it.

Lastname_Firstname_Mission2.pdf

On a Chromebook: open the Files app › Downloads, right-click the file, choose Rename. Do not type a second .pdf on the end.

Upload it to Google Drive

Five steps
  1. Open Drive with your school account

    Go to drive.google.com, or the 9-dot grid › Drive. Check the account circle top-right — it has to be your school account, not personal Gmail.

  2. Open the Mission 2 folder

    Shared with me › the class folder › Mission 2. Uploading to My Drive instead does not turn anything in — I cannot see your My Drive.

  3. Upload the file

    Click + New › File upload, pick your renamed file from Downloads, and press Open. Dragging the file from the Files app onto the folder window does the same thing.

  4. Wait for the upload to finish

    A progress box appears in the bottom corner. Wait for 1 upload complete. Do not close the tab while it is still moving — that data is in transit, and interrupting it means no file arrives.

  5. Verify with your own eyes

    Refresh the folder. You should see your file, with your name on it. Click it — if it opens and looks right, you are done. If it opens blank or blurry, export it again as a PDF.

Access control: the Mission 2 folder is already shared with the class, so anything you drop in it is shared correctly the moment it lands. Do not change the folder's sharing settings, and never share the folder link outside our class — that folder holds other students' work.
